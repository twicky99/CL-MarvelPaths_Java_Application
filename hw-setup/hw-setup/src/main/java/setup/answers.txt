1. Why did Fibonacci fail the testThrowsIllegalArgumentException< test? What (if anything) did
you have to do to fix it? If you did not have to change anything to fix this issue, explain why.

The 0th term in the fibonacci sequence is 1, but anything 0 or below was considered negative
and therefore invalid. To solve this issue I made it so the program did not include
0 as a negative number (n < 0 instead of n <=0), so it would be counted as less than
or equal to 2 instead. All numbers less than or equal to 2 that are not negative return 1.

than two as the test requires. They are not less than 0 either so both count
as a base case and all base cases return 1. (Note when program is changed latter on
