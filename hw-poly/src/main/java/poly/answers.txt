## Part 2
###########################################################################

1. Calls to checkRep in RatTerm

A call to checkRep() was occurred whenever change was made. This included when objects
were created so every constructor called checkRep() at the end after the new RatTerm was
changed. Because RatTerm is immutable, checkRep() was only called when a RatTerm was
created. This was always at the end of methods as the only reason to create a RatTerm
is if you are returning a RatTerm and therefore creating a RatTerm is the last thing you
are doing.
